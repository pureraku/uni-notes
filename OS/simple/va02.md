# Value Added 2: Debugging C with GDB

## Aim
Compile a C program with debug symbols and inspect it in GDB.

## Compile and debug
`cc -g -O0 va02.c -o va02`

Start `gdb ./va02`, then enter `break main`, `run`, `next`, `print value`, `print sum`, and `continue`. Use `quit` to exit. The loop sums integers 1 through 5 and prints each intermediate total.
