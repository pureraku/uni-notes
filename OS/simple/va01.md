# Value Added 1: Shell concepts demonstrated in C

## Aim
Practice command-line arguments, variables, arithmetic, conditionals, `switch`, and loops in C.

## Compile and run
`cc -std=c11 va01.c -o va01 && ./va01 12 5`

The two integer arguments are validated before use. This is a C implementation of the concepts in the shell exercise, as requested; it is not a shell script.
