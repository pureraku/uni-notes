# Experiment 1: Linux basics

## Aim
Practice common Linux commands and learn what they do. OS installation is completed through the machine’s installer; this program is for command practice.

## Program
The menu runs one of several fixed, read-only commands, such as `date`, `pwd`, `ls -la`, and `head`. It does not accept arbitrary command text.

## Compile and run
`cc -std=c11 exp01.c -o exp01 && ./exp01`

Choose a menu number. The file examples use `/etc/passwd`, which is present on typical Linux systems.
