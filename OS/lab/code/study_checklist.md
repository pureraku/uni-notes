# C Programming Revision Checklist

## Lab 1
- [ ] I can compile and execute a C program in Linux.
- [ ] I know the purpose of `gcc`, `./program`, and basic terminal commands.

## Lab 2
- [ ] I know the return values of `fork()`.
- [ ] I can use `getpid()` and `getppid()`.
- [ ] I understand why `wait()` is used.
- [ ] I can write a parent/child branch.

## Lab 3
- [ ] I can create a pthread.
- [ ] I can pass an argument to a thread.
- [ ] I can join a thread.
- [ ] I understand why shared variables may need synchronization.

## Lab 4
- [ ] I can initialize/use/destroy a semaphore.
- [ ] I understand `sem_wait()` and `sem_post()`.
- [ ] I understand mutex + condition variable as a monitor-style approach.

## Lab 5
- [ ] I understand the reader/writer compatibility rules.
- [ ] I can implement a basic reader-preference solution.
- [ ] I know where starvation can occur.

## Lab 6
- [ ] I understand the fork-acquisition deadlock pattern.
- [ ] I can implement a deadlock-avoiding strategy.
- [ ] I can explain deadlock vs starvation.

## Lab 7
- [ ] I can calculate Need.
- [ ] I can implement the safety algorithm.
- [ ] I can produce a safe sequence.

## Labs 8–9
- [ ] I can construct a Gantt chart.
- [ ] I know CT, TAT, WT.
- [ ] I can implement FCFS.
- [ ] I can implement non-preemptive SJF.
- [ ] I can implement priority scheduling.
- [ ] I can implement Round Robin.
